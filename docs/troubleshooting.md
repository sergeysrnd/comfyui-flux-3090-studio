# Если что-то пошло не так

## Какой JSON открывать

Только **[FLUX_3090_STUDIO.json](../FLUX_3090_STUDIO.json)** в корне репозитория.
В нём уже есть оба этапа. Перетащи JSON на холст или открой через
меню ComfyUI → File → Open. Старые отдельные схемы сохранены в истории Git.

## Вместо нового кадра обрабатывается старый PNG

Проверь **ЭТАП**. OFF запускает GENERATE, ON запускает FINISH.
FINISH всегда использует файл в средней верхней ноде **ВЫБРАННЫЙ PNG**.
Загрузи нужный base PNG, проверь превью и нажми Run.

## Invalid image file перед первой генерацией

На новом ПК файл с маяком не появляется автоматически. Выбери любой PNG
через кнопку папки в средней верхней ноде. Например, скачай
[пример](../examples/FLUX_3090_selected_lighthouse.png).
ComfyUI проверяет существование этого файла при валидации всего графа,
хотя сама ветка FINISH в этапе GENERATE не исполняется.
После поиска кадра выбери здесь свой понравившийся base PNG.

## PNG открыл другую схему

PNG может содержать workflow. Загружай кадр через кнопку папки в ноде изображения,
а JSON схемы — на холст. Актуальный JSON можно открыть заново в отдельной вкладке,
сохранив свои изменения текущей схемы отдельно.

## Изменение seed в GENERATE не меняет результат FINISH

Так и задумано: на этапе FINISH генерация не выполняется.
Верни ЭТАП OFF для нового поиска либо выбери другой PNG для обработки.
При increment после Run показывается следующий seed; для обработки достаточно PNG.

## Промт, denoise или шаги ничего не меняют в FINISH

Эти поля действуют, только когда включена **Дорисовка FLUX**.
При OFF выполняется обычное увеличение; масштаб и AI upscale продолжают действовать.

## Сравнение пустое или не движется

Включи **Nodes 2.0**, выполни Run и веди курсор по картинке без зажатой кнопки.
В GENERATE обе стороны одинаковы. В FINISH при AI upscale OFF и дорисовке OFF
стороны также совпадают: обе показывают Lanczos.

## Модель увеличения не найдена

Нужен `RealESRGAN_x2plus.pth` в `models/upscale_models/` текущей установки.
Обнови определения нод через ComfyUI → Edit → Refresh Node Definitions
или перезапусти ComfyUI. Custom nodes не требуются.

## Нода свернулась

Разверни её стрелкой в заголовке. В исходном JSON все ноды активны;
рабочие этапы выбираются переключателем ЭТАП, без Mute.

## Дорисовка изменила мелкие предметы

Сравни с вариантом без дорисовки. Уменьши denoise либо выключи её.
Если сгладилась фактура при Real-ESRGAN, сравни с Lanczos.

## Ошибка памяти

Верни batch 1, вход 1344 × 768, масштаб 1.5. Для начала выключи дорисовку.
В проверенной конфигурации FLUX загружается в FP8, T5 — FP16.
Другие размеры требуют отдельной проверки. См. [измерения](benchmarks.md).
