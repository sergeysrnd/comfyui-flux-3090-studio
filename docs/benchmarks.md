# Что было проверено

Один пейзаж с маяком, RTX 3090 24 ГБ, RAM 32 ГБ, Windows,
ComfyUI Desktop 1.1.8 / ComfyUI 0.43.2 / frontend 1.57.4.
Исходный размер 1344 × 768, финальный 2016 × 1152.

Это **одиночные проверочные запуски** с прогретыми моделями и частью кеша.
Это не статистический бенчмарк и не гарантированная скорость на другом ПК.
Загрузка моделей с диска, offload и незакешированный промт могут увеличить время.

| Проверка | Время | Результат |
| --- | ---: | --- |
| GENERATE, 20 шагов, API | 29.444 с | Успешно |
| GENERATE, 20 шагов, Run в Desktop | 30.092 с | Успешно, subgraph и сохранение PNG |
| GENERATE, 28 шагов, API | 42.430 с | Успешно |
| Real-ESRGAN x2 → масштаб 1.5, API | 2.318 с | 2016 × 1152 |
| FINISH, AI ON / refine OFF, Desktop | 2.278 с | Успешно, сравнение и сохранение |
| Lanczos ×1.5, API | 0.432 с | 2016 × 1152 |
| Refine от Lanczos, 14 шагов / 0.18, обычный VAE | 52.544 с | Успешно |
| Те же параметры, tiled VAE 512 | 52.794 с | Успешно |
| FINISH, AI ON / refine ON, Desktop | около 55.55 с | Успешно, PNG и метаданные |

Проверены обе ветки AI/Lanczos, включение/выключение refine и реальные запуски
внешних native subgraphs из Desktop. При отключённом refine ветка FLUX/CLIP/VAE
не выполнялась. После тестов refine сохранён выключенным.

При переносе генерации в subgraph сохранены модель, промт, seed, размеры,
guidance, CFG 1, Euler/simple и 28 шагов. Сравнение пикселей показало полное
совпадение с базовым результатом предыдущей схемы v1 на этой же установке.

Обычный и tiled VAE различались на 0.25 секунды в одной паре запусков.
Этого недостаточно для вывода об ускорении. В итоговой схеме оставлен обычный VAE;
ComfyUI имеет встроенный переход к tiled обработке при OOM в VAE.
